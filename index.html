Workflow

Load → Analyze → confirm tempo/meter → choose ALIGN points → phrase-snap the arrangement → grid-correct or warp → trim/select a region → fade/crossfade → audition → Render Changes → Export WAV.

Analysis intelligence

AUTO scores 3/4, 4/4 and 6/8 bar cycles and reports confidence. The project meter follows Track A when possible; you can force a meter at any time. Tempo analysis also retains raw half/double-time alternatives instead of hiding octave corrections.

Arrangement editing

Select a track, place the playhead, then I / O sets nondestructive IN and OUT points. REGION selects a reusable project range; Shift-drag bypasses snapping. Region → Loop makes that range the audition/export loop.

Fades

With a REGION selected, FADE IN / OUT applies to the active track instantly in the mix layer. A→B crossfades Track A out and Track B in over the same region. These do not require a DSP render.

Render engine

Timing-only renders preserve clean PCM outside changed warp regions and run granular DSP only where timing actually changes. FAST / BALANCED / HIGH control overlap/search cost. Click the render button again while calculating to cancel.

Project transport

Click or drag the ruler to seek. Playback starts at the playhead. 4 / 8 / 16 / 32-bar audition loops and phrase snapping use the current project meter.

Session safety

Phase remembers the latest project map locally and supports metadata Undo / Redo. Audio files remain local; reload the same source files to reconnect a restored session.

Audition + mix

MUTE and SOLO are audition helpers. Track LEVEL, trims and fades are applied to playback, focused alignment audition, and WAV output.

Render model

Dragging stays visual-only and instant. Playback keeps using the last completed audio until Render Changes runs the worker. Source audio is never overwritten.
