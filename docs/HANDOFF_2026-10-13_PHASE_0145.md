## Phase 0.14.5 — released and accepted in GitHub
**PR:** [#7 — live drag and bounded section export](https://github.com/aerovista-us/phase/pull/7)  
**Merged release commit:** `a982bb1b4639cf125ca8f39003d2e72a14cc9da9`  
**PR branch:** `feature/phase-0145-drag-and-section-export` (merged)

1. Master Assembly pointer drag previews a clip's future position before release, uses 5px motion threshold and pointer capture, Escape/pointercancel rollback, and exactly one undoable commit on pointer release. Dragging does not edit the original source.
2. Mix & Sync MOVE uses live CSS waveform/marker preview rather than triggering repeated expensive renders while dragging. Shift means free positioning; the selected snap mode applies otherwise. Commit and audio preview refresh happen once on pointer release. Escape cancels without a model edit.
3. Master Assembly adds **SET IN**, **SET OUT**, numeric seconds, and **EXPORT SECTION WAV**. It passes only intersecting original source windows through `renderMixRegion`, preserving fades and 16-bit stereo PCM, with a 128MiB section output safety budget.
4. **Not included:** full-length incremental WAV writer, partial AudioBuffer allocation for Splice Inspector, independent record listening or full NXCore runtime deployment.
